# Лабораторная работа №2

В ходе лабораторной работы разработан сайт «Библиотека» с использованием HTML и CSS. Созданы три страницы:

- Главная - описание библиотеки, изображение и список услуг.
- Книги - таблица с названиями книг, авторами, годами издания и количеством экземпляров.
- Контакты - адрес, электронная почта и режим работы.

На всех страницах добавлено меню навигации. Оформление вынесено в отдельный файл style.css.
