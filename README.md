# Лабораторная работа №2

В ходе лабораторной работы разработан сайт «Библиотека» с использованием HTML и CSS. Созданы три страницы:

- Главная - описание библиотеки, изображение и список услуг.
- Книги - таблица с названиями книг, авторами, годами издания и количеством экземпляров.
- Контакты - адрес, электронная почта и режим работы.

На всех страницах добавлено меню навигации. Оформление вынесено в отдельный файл style.css.

# Лабораторная работа №3

В ходе работы изучена структура проекта и реализованы 10 функций в файле src/core.js:

- Проверка целого числа и степени двойки.
- Формирование массива чётных чисел от 2 до 20.
- Вычисление суммы чисел с помощью цикла и рекурсии.
- Вычисление факториала и чисел Фибоначчи.
- Создание функции с сохранением результата операции.
- Создание генератора арифметической последовательности.
- Глубокое сравнение объектов и массивов.

Использованы условия, циклы, массивы, побитовые операции, рекурсия и замыкания. Для проверки решений предусмотрены готовые тесты на Mocha, запускаемые командой `npm test`.
